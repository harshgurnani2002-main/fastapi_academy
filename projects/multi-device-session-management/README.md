# Multi-Device Session Management

Enterprise Distributed Session Platform featuring:
- **Device Fingerprinting & Concurrent Device Caps** (Max 3 active devices; auto-evicts oldest)
- **Sliding TTL Expiration**
- **Session ID Rotation against Fixation Attacks**
- **Instant Atomic "Logout Everywhere" Invalidation**
