# FastAPI Security Hardening Lab

Interactive OWASP Top 10 API Security Lab demonstrating vulnerability exploits and their hardened mitigations:
- **BOLA / IDOR Mitigation (API1:2023)**
- **Mass Assignment Mitigation (API3:2023)**
- **SSRF Defense Engine & Cloud Metadata Protection (API7:2023)**
- **SQL Injection Prevention (Parameterized Bindings)**
- **Path Traversal & Magic Byte File Upload Hardening**
- **Sliding Window Token Bucket Rate Limiter (API4:2023)**
- **Security Headers (HSTS, CSP, NoSniff, Frame-Options)**

## Run Pytest Suite
```bash
pytest -v
```
