# Production API Design System

API Design Engineering Platform demonstrating:
- **Parallel REST Versioning** (`/v1/customers` flat vs `/v2/customers` structured)
- **Base64 Keyset / Cursor Pagination** with `has_next` and `next_cursor`
- **Filtering & Search DSL**
- **Standardized Machine-Readable Error Responses**
